🌍 Explore the World - Travel Website

This is a responsive travel website designed to help users explore different destinations with ease. The website provides detailed information about each place including travel routes, best time to visit, weather conditions, and nearby attractions.

✨ Features:
- Responsive design (mobile, tablet, desktop)
- Interactive travel routes (road, rail, air using Google Maps)
- Distance calculation from user location
- Beautiful UI with animations and hover effects
- Form validation for user experience feedback
- Organized multi-page structure with reusable CSS

🛠 Technologies Used:
- HTML
- CSS
- JavaScript

🎯 Purpose:
To create a user-friendly travel guide that combines functionality and design, helping users plan their trips efficiently.
